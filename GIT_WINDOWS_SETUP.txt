warning: in the working copy of 'file.ipynb', 
LF will be replaced by CRLF the next time Git touches it

Ini NORMAL dan AMAN! Git otomatis menghandle line endings.


📋 PENJELASAN:
═══════════════════════════════════════════════════════════

Windows menggunakan:   CRLF (\r\n)
Linux/Mac menggunakan: LF (\n)

Git akan:
✅ Convert ke LF saat commit (di repository)
✅ Convert ke CRLF saat checkout (di Windows)

Ini memastikan kompatibilitas cross-platform!


🔧 SETUP GIT UNTUK WINDOWS (One-time):
═══════════════════════════════════════════════════════════

Jalankan command ini sekali saja:

git config --global core.autocrlf true

Ini memberitahu Git untuk:
- Convert CRLF → LF saat commit
- Convert LF → CRLF saat checkout


📝 UNTUK TEAM ANDA:
═══════════════════════════════════════════════════════════

Semua anggota team (jika Windows) jalankan:

git config --global core.autocrlf true

Jika ada yang pakai Linux/Mac, mereka jalankan:

git config --global core.autocrlf input

📚 TENTANG LINE ENDINGS:
═══════════════════════════════════════════════════════════

CRLF = Carriage Return + Line Feed
- Used by: Windows
- Characters: \r\n

LF = Line Feed only
- Used by: Linux, Mac
- Characters: \n

Git repository: Always use LF (standard)
Your working directory (Windows): CRLF

Git auto-converts! No action needed from you.
